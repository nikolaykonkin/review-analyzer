## Что не реализовано и почему

Реализованы только точки входа `cmd/service/main.go` и `cmd/bot/main.go` (пустые `main`). Пока не реализованы: загрузка конфигурации, импорт отзывов из CSV, хранение в PostgreSQL, анализ через GigaChat, фоновая обработка, REST API, Telegram-бот, метрики, CI. Проект в разработке, эти части появляются по мере готовности.
